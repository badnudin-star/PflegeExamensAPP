# Fallbeispielimport

Die 30 nummerierten PDFs aus `QuellenExamen/Fallbeispiele` wurden einmalig unverändert gelesen und als 30 Fälle mit 494 nummerngleich zugeordneten Aufgaben/Musterlösungen in den Offline-Katalog übernommen. Je zehn gehören zu Prüfungstag 1, 2 und 3; das ist keine Sortierung nach einem Kalenderdatum. Titel, einleitende Hinweise, Aufgabenhinweise, Lösungs-Hinweise und Quellenabschnitt bleiben im Katalog erhalten. Das PDF-Änderungsdatum vom Drive-Inventar ist technische Metadaten, kein behauptetes Veröffentlichungsdatum. Die PDFs wurden nicht verändert.

Der Import prüft eindeutige Abschnitts- und Nummernstruktur; dies ist keine fachliche Prüfung und keine Garantie für verlustfreie PDF-Textextraktion. Fachliche Aktualität, Rechte und Übernahme vor Verwendung/Veröffentlichung prüfen. Ein optionaler Drive-Abgleich steht bei entsprechender Konfiguration zur Verfügung; siehe `tools/learning_import/README.md`.

Für einen erneuten Import `pip install -r tools/learning_import/requirements.txt` und `python tools/case_import/import_cases.py --directory /pfad/zum/download --base /pfad/zum/katalog-ohne-faelle.json --output /anderer/pfad/katalog.json --modified-date JJJJ-MM-TT`. Das Werkzeug erwartet exakt die vorliegenden 30 Dateien und verweigert das Überschreiben vorhandener Fälle. Für zukünftige Erweiterungen ist ein konfliktfreies Abgleichsverfahren erforderlich. Tests: `python -m unittest discover -s tools/case_import -v`.
